## 抽取
- 温度、风量的上下限按车型可能不同，按车型写进车型参数（如 temp_min / temp_max / fan_max），不要拆需求点。
- 主驾 / 副驾 / 后排分区是不同的需求点。

## 编写
- 温度统一写“XX℃”，播报写“XX 度”；上下限用车型参数 ${temp_min} / ${temp_max}。
- 空调关闭时调温度：期望写清楚是先开空调再调温，还是拒绝并提示。
- 需要确认车辆真实状态（空调是否真的打开、温度是否真的设定）时，在预期里写明，生成测试代码时会加车辆属性断言。
