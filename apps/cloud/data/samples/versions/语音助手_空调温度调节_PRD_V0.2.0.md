## 1 概述

用户在车内通过语音助手调节空调温度，车机执行后在空调界面显示新温度，并语音播报结果。

## 2 车型打点

| 需求 | A01国内 | A01国际 | B01欧版 | D01 | E01 |
|---|---|---|---|---|---|
| 3.1 设定温度 | ● | ● | ● | ● | ● |
| 3.2 相对调节 | ● | ● | ● | ● | ● |
| 3.3 超范围拒绝 | ● | ● | ● | ● | ● |
| 3.4 上下限提示 | ● | ● | ● | ● | ● |
| 3.5 空调未开启 | ● | ● | — | ● | ● |
| 3.7 调到最高 | ● | ● | ● | ● | ● |

温度上限：E01 为 30℃，其余车型为 32℃；温度下限均为 16℃。

## 3 功能需求

前置条件：车机已上电；语音助手已用唤醒词“你好千禾”唤醒。

3.1 用户说“空调调到 N 度”或“把温度调到 N 度”，N 为 16 到温度上限之间的整数：空调温度设为 N，空调界面显示 N℃，播报“已为您调到 N 度”。

3.2 用户说“温度高一点”或“温度低一点”：在当前温度上加或减 2℃，界面显示新温度，播报“已为您调到 M 度”（M 为新温度）。

3.3 N 小于 16 或大于温度上限：不改变当前温度，播报“温度可调范围为 16 到温度上限度”。

3.4 当前为温度上限时说“温度高一点”：温度保持不变，播报“已经是最高温度了”；当前为 16℃ 时说“温度低一点”：温度保持 16℃，播报“已经是最低温度了”。

3.5 空调关闭时说“空调调到 N 度”：先开启空调，再设为 N℃，播报“已为您打开空调并调到 N 度”。

3.7 用户说“空调调到最高”：温度设为温度上限，界面显示对应温度，播报“已为您调到 N 度”（N 为温度上限）。
