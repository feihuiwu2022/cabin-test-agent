# 语音助手 · 空调温度调节 PRD

| 项目 | 内容 |
|---|---|
| 文档版本 | 0.1.0 |
| 适用车型 | A01国内、A01国际、B01欧版、D01、E01 |
| 所属模块 | 语音助手 / 空调 |

## 1 概述

用户在车内通过语音助手调节空调温度，车机执行后在空调界面显示新温度，并语音播报结果。

## 3 功能需求

前置条件：车机已上电；语音助手已用唤醒词“你好千禾”唤醒。

3.1 用户说“空调调到 N 度”或“把温度调到 N 度”，N 为 16–32 的整数：空调温度设为 N，空调界面显示 N℃，播报“已为您调到 N 度”。

3.2 用户说“温度高一点”或“温度低一点”：在当前温度上加或减 1℃，界面显示新温度，播报“已为您调到 M 度”（M 为新温度）。

3.3 N 小于 16 或大于 32：不改变当前温度，播报“温度可调范围为 16 到 32 度”。

3.4 当前为 32℃ 时说“温度高一点”：温度保持 32℃，播报“已经是最高温度了”；当前为 16℃ 时说“温度低一点”：温度保持 16℃，播报“已经是最低温度了”。

3.5 空调关闭时说“空调调到 N 度”（N 在 16–32 内）：先开启空调，再设为 N℃，播报“已为您打开空调并调到 N 度”。

3.6 从用户说完指令到车机开始播报不超过 1.5 秒。
